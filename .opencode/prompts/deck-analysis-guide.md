# 七圣召唤 AI 对战 — 卡组分析指南

> 提炼自 `@gi-tcg/llm-deck-analyzer` 包的 SKILL.md，仅保留对战 AI 需要的部分。

## 开局必须做的事

对战开始后、进入决策循环前，完成以下分析（**只做一次**，不要每回合重复）：

1. 调用 `get_player0_deck` 和 `get_player1_deck` 获取双方卡组代码
2. 调用 `analyze_deck` 分析己方卡组（获得纯数据上下文：角色、技能、卡牌效果、费用、衍生物；另有启发式 baseline 作参考）
3. 调用 `analyze_matchup` 分析双方对局（获得双方纯数据上下文 + 启发式 baseline）
4. 根据分析结果制定整体对局策略，后续每个决策回合参考此策略

## 卡牌效果准确性约束（必读）

**你必须严格依据 tool 返回结果中的卡牌描述来理解效果，严禁凭记忆编造。** 以下是最容易出错的卡牌：

| 卡牌名 | ❌ 常见幻觉 | ✅ 实际效果 |
|--------|------------|------------|
| 星天之兆 | 莫娜的天赋牌 | **事件牌**，使出战角色获得1点充能，2无色费用 |
| 本大爷还没有输！ | 角色血量低时触发 | **战斗行动**，我方角色被**击倒**后才能打出，生成1万能+1充能 |
| 赌徒的耳环 | 击杀后获得2骰 | 敌方被击倒时，若附属角色为**出战角色**，生成2万能（整局限3次） |
| 唐杜尔烤鸡 | 单个角色E+2 | **全体角色**下次E伤害+2（战斗料理） |
| 交给我吧！ | 免费切人 | **快速行动**，下次切换视为快速行动（一次性，与莫娜被动不同） |
| 换班时间 | 免费切人 | 下次切换少花1个元素骰 |
| 送你一程 | 消灭召唤物 | 使敌方召唤物**可用次数-2** |
| 白垩之术 | 转移1点充能 | 从最多2个后台角色各转移1点充能到出战角色 |
| 提米 | 3回合后抓牌 | 初始已有1只鸽子，2回合后激活 |

**通用规则：**
- `[天赋]` vs `[事件]` 是不同的卡牌类别，不可混淆
- `[战斗行动]` 打出后回合交给对方；`[快速行动]` 不交出回合
- `[料理]` 每回合限1张；`[秘传]` 全场限1张
- 角色被动技能 ≠ 卡牌效果（如莫娜「虚实流动」≠「交给我吧！」）

## 分析结果的使用

`analyze_deck` 返回的 JSON 包含以下结构：

### baseline（启发式基线）

启发式分析，作为粗略参考。**不建议直接照搬**，应基于 deckContext 自行推理。

### deckContext（纯数据卡组上下文）

- `characters[]`：角色完整信息（name/elements/weapon/hp/maxEnergy/skills[].type/description/playCost）
- `cards[]`：卡牌完整信息（name/type/subtype/description/playingDescription/playCost/tags/relatedCharacterTag）
- `cardCounts[]`：重复卡牌（用于换牌决策）
- `entityDescriptions{}`：衍生物/召唤物/战斗状态效果（含官方描述和元数据标签）
- `generatedHandCards{}`：角色技能生成的手牌（含描述和费用）
- `summary{}`：卡组统计（元素分布/装备事件支援计数/天赋/共鸣等）

**⚠️ 不再包含 `analysis` 块**（triggerChains / comboClock / skillEfficiency / resourceCycles / zonePressure / freeCards 均已移除）。你需要从角色技能和卡牌描述中自主推理 combo、资源曲线、技能效率等。

### MatchupAnalysis（对局分析）

- `baseline`：对局启发式基线（优势/关键互动/策略/预测胜率，仅作参考）
- `deckAContext` / `deckBContext`：双方纯数据上下文（同 analyze_deck 的 deckContext 结构）

### 策略提取要点

1. **开局角色选择**：阅读角色技能（费用/效果/元素），自主推理最优首发——优先考虑能量经济和元素覆盖
2. **关键卡牌优先级**：从 `cards[]` 中基于效果选出关键卡，手牌中有这些卡时优先保留（换牌阶段）
3. **对局节奏**：基于双方角色和卡牌效果推理快攻/站场/控制节奏
4. **威胁识别**：阅读对手 `cards[]` 和 `characters[]`，预判对方可能的展开
5. **combo 推理**：从卡牌描述中识别触发/生成/减费联动，自主推理 combo 序列
6. **资源曲线**：从卡牌描述中识别抽牌/生骰/减费效果，推理资源管理策略

## 角色技能与衍生物联动

分析结果中包含角色的完整技能列表和衍生物信息。需要注意：

- 角色的E/Q/被动可能生成**召唤物**或**战斗状态**（如凝光璇玑屏、水形幻人半幻人），这些效果应纳入整体策略
- 衍生物标签：`[角色阵亡后保留]`（不依赖角色存活）、`[减伤]`、`[护盾]` 等影响战术判断
- 生成手牌（如刻晴雷楔、丝柯克虚境裂隙）可能被初始牌组中的减费牌覆盖

## 禁止事项

- 不要在分析中输出强度数字评分（如 "7.5/10"）
- 不要空口估计具体胜率百分比（可以说"对快攻偏劣势"，不能说"胜率约55%"）
- 不要对未在分析结果中出现的卡牌做具体效果断言
