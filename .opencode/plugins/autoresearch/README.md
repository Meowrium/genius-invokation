Autoresearch is installed here as an OpenCode skill-only adaptation of
`uditgoenka/autoresearch`.

What is included:
- `skills/autoresearch` from upstream

What is not wired up:
- Claude-specific plugin marketplace metadata
- Claude-specific custom command registration under `commands/`

Use it by asking OpenCode to apply the `autoresearch` skill in natural
language. The upstream slash subcommands may not be available in OpenCode.
